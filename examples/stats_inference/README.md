# Inferential statistics

Compute a t confidence interval, one-sample and Welch t-tests, a chi-square
goodness-of-fit test, and Benjamini-Hochberg p-value adjustment using only
`vsl.stats`.

Run it from the V modules directory:

```sh
cd ~/.vmodules
v run ./vsl/examples/stats_inference/main.v
```

See the [`vsl.stats` API](../../stats/README.md) for hypotheses, sidedness,
degrees of freedom, and input policy details.
