# BFGS multivariate minimization

This example minimizes the two-dimensional Rosenbrock objective using its
analytic gradient and reports convergence and evaluation diagnostics.

Run it from the V modules directory:

```sh
cd ~/.vmodules
v run ./vsl/examples/roots_bfgs/main.v
```

The public API is documented in [`vsl.roots`](../../roots/README.md) and the
[multivariate minimization guide](../../docs/scientific-computing/06-multivariate-minimization.md).
