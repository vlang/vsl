# Nelder-Mead multivariate minimization

This example minimizes the two-dimensional Rosenbrock objective and reports
the best point, final simplex spreads, status, and evaluation counts.

Run it from the V modules directory so V can resolve the local VSL clone:

```sh
cd ~/.vmodules
v run ./vsl/examples/roots_nelder_mead/main.v
```

The example uses the public API documented in [`vsl.roots`](../../roots/README.md).
