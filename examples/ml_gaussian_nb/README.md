# Gaussian Naive Bayes

This example trains `vsl.ml.GaussianNB` on a small two-class dataset and prints
class predictions with normalized probabilities.

Run from the V modules directory:

```sh
v run ./vsl/examples/ml_gaussian_nb/main.v
```

See [`ml/README.md`](../../ml/README.md#gaussian-naive-bayes) for variance
smoothing, class prior, and input semantics.
