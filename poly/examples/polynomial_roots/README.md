# Polynomial roots

This example solves a quadratic and a cubic equation and prints their real roots.

Run it from the V modules directory:

```sh
cd ~/.vmodules && v run ./vsl/poly/examples/polynomial_roots/main.v
```

Expected roots are `[1, 2]` for `x² - 3x + 2` and `[1, 2, 3]` for
`x³ - 6x² + 11x - 6`.
