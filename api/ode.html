ode #

vsl.ode

solve_rk23 integrates first-order systems with an adaptive Bogacki-Shampine 3(2) explicit Runge-Kutta method. It supports vector states, forward or backward integration, error tolerances, a maximum step size, and execution limits. The method is intended for non-stiff systems.

import math
import vsl.ode

fn exponential_system(_ f64, state []f64, _ []f64) []f64 {
    return [state[0]]
}

result := ode.solve_rk23(exponential_system, ode.RK23Params{
    t_start:       0.0
    t_end:         1.0
    initial_state: [1.0]
    abs_tol:       1e-9
    rel_tol:       1e-7
})!
assert math.abs(result.state[0] - math.e) < 1e-5

The result includes the last accepted state, scaled local error norm, function evaluation count, accepted/rejected step counts, and a termination status. This first ODE slice does not provide stiff methods, dense output, event handling, or a full trajectory.

fn solve_rk23 #

fn solve_rk23(f ODEFunction, params RK23Params) !RK23Result

solve_rk23 integrates y'=f(t,y) from t_start to t_end using adaptive Bogacki-Shampine 3(2) steps. It is intended for non-stiff systems.

enum RK23Status {
	converged
	max_steps
	max_evaluations
	non_finite_function_value
	invalid_function_output
	precision_limit
	non_finite_estimate
}

RK23Status reports why the adaptive integrator stopped.

struct RK23Params #

@[params]
struct RK23Params {
pub:
	t_start         f64
	t_end           f64
	initial_state   []f64 @[required]
	function_params []f64
	initial_step    f64
	max_step        f64
	abs_tol         f64 = 1e-9
	rel_tol         f64 = 1e-6
	max_steps       int = 100000
	max_evals       int = 400000
}

RK23Params configures an adaptive Bogacki-Shampine 3(2) initial-value solve.

struct RK23Result #

struct RK23Result {
pub:
	t          f64
	state      []f64
	error_norm f64
	n_calls    int
	n_steps    int
	n_accepted int
	n_rejected int
	status     RK23Status
}

RK23Result contains the last accepted state and adaptive-step diagnostics.
